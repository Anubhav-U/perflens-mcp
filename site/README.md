# PerfLens landing page

One-page site explaining PerfLens, with an interactive report from real audits of two demo pages:
`public/demo/slow.html` (deliberately slow) and `public/demo/fast.html` (the same page with PerfLens's fixes applied).
It is not part of the npm package.

## Run locally

```bash
npm install
npm run dev        # generates demo assets first, then starts Next.js
```

## Refresh the demo results

The numbers on the page come from `src/data/demo-results.json`, produced by real Lighthouse runs:

```bash
npm run build && npx next start -p 3123     # in site/
npm run precompute                          # in the repo root, in another terminal
```

Demo images, CSS and JS in `public/demo/slow/` and `public/demo/fast/` are generated by
`scripts/make-demo-assets.mjs` (runs automatically before `dev` and `build`) and are not committed.
